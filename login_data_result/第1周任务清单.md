# 第 1 周任务清单（Python 接口测试实战）

> 目标：**从"能看懂"到"写得出"**，一周内独立写出调用接口并处理返回的脚本。
> 节奏：每天 1-2 小时，**每天有可见产出，做完即打勾**。
> 实战场景：接口测试（用 requests），所有练习用公开免费接口，无需账号。

## 练习站点（免费、安全、可反复请求）
- httpbin.org —— 专门用来练习 HTTP 请求/响应；**首页即接口文档**：https://httpbin.org/
- https://jsonplaceholder.typicode.com —— 模拟 REST 数据；**首页即接口文档**：https://jsonplaceholder.typicode.com/

### ⭐ 接口文档速查（做任务前先读它，参数名只能从这里来）

**jsonplaceholder `/posts`（GET）可用的 query 参数：**
| 参数 | 含义 | 示例 |
|------|------|------|
| `userId` | 按用户 id 过滤 | `/posts?userId=1` |
| `_limit` | 限制返回条数 | `/posts?_limit=5` |
| `_page` | 指定页码 | `/posts?_page=2` |

**jsonplaceholder 单条（GET）：** `/posts/1`（路径参数 `1` = 帖子 id）→ 200，返回 `{userId, id, title, body}`

**httpbin（GET）：** `/get`（回显 args/headers/url）、`/headers`、`/status/405`（练错误码）
**httpbin（POST）：** `/post`（回显 form/json/data）

## 每天任务

### D1｜破冰：调通第一个接口
- [ ] 安装 Python（含 pip），安装 VSCode + Python 扩展
- [ ] `pip install requests`
- [ ] 写脚本请求 `https://httpbin.org/get`，打印返回内容
- **产出**：终端成功打印出接口返回的 JSON
- 提示：先别管语法，能跑出结果就是胜利

### D2｜封装函数
- [ ] 把 D1 的请求代码封装成一个函数 `def get(url): ...`
- [ ] 调用函数获取结果
- **产出**：一个可复用的 `get()` 函数
- 提示：函数 = 把"重复的代码"包起来，方便复用

### D3｜传参
- [ ] 给请求加 query 参数（`params=`）和请求头（`headers=`）
- [ ] 请求 `https://jsonplaceholder.typicode.com/posts/1`
- [ ] 带参数请求列表接口：`params={'userId': 1, '_limit': 5}`（参数名来自上方「接口文档速查」）
- **产出**：能根据参数获取不同数据
- 提示：params 是一个字典 `{键: 值}`，requests 会自动拼成 URL 后面的 `?key=value`
- **⚠ 本次教训**：参数名不能靠猜，**必须查接口文档**

### D4｜异常处理
- [ ] 用 `try/except` 包住请求
- [ ] 加超时（`timeout=`）和状态码判断（`resp.status_code == 200`）
- [ ] 故意请求一个不存在的地址，观察是否优雅报错
- **产出**：请求失败时不崩溃、能打印原因
- 提示：真实测试中"失败处理"比"成功"更重要

### D5｜用「类」封装
- [ ] 写一个简单类 `ApiClient`，包含 `get()` 方法
- [ ] 实例化并调用
- **产出**：一个 `ApiClient` 类
- 提示：类 = 把"数据和操作"打包，接口测试框架的核心就是类

### D6｜写入文件
- [ ] 把接口返回结果保存为 `.json` 文件
- [ ] `json.dumps(...)` + 文件写入
- **产出**：一个保存结果的脚本 + 一个 .json 文件
- 提示：中文写入记得 `encoding="utf-8"`

### D7｜综合 + 复盘
- [ ] 拉取 `jsonplaceholder` 的 posts 列表，再取单个 post 详情
- [ ] 打印关键字段，并保存到文件
- [ ] 复盘：本周哪些卡住、下周想加强什么
- **产出**：一个完整小脚本 + 本周复盘记录
- 提示：把 D2~D6 的知识串起来，这就是一个迷你接口测试脚本
