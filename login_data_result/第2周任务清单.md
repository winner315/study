# 第 2 周任务清单（Pytest 接口测试框架）

> 目标：把第 1 周的**脚本**升级成规范的 **Pytest 测试框架**（用例 / fixture / 参数化）。
> 节奏：每天 1-2 小时，**每天有可见产出，做完即打勾**。
> 本周结束你必须能说出一句：**"我会用 pytest 写接口自动化用例。"**
> 网络提示：继续用 `jsonplaceholder`；若一直超时，临时换 `https://httpbin.org`。

## 本周核心概念（先混个脸熟，做的时候自然懂）
| 概念 | 一句话解释 |
|------|-----------|
| **用例（test）** | 文件名 `test_*.py`、函数名 `test_*`，pytest 会自动发现并执行 |
| **断言** | 直接用 `assert`，失败会标红并给出原因（不需要第三方库） |
| **fixture** | 用例的"前置准备"，比如"先造一个可用的 client / 登录 token" |
| **参数化** | 一个用例，喂多组数据，自动跑 N 遍 |

## 建议目录结构
```

├── conftest.py          # 共享 fixture（D6 才建）
```

## 每天任务

### D1｜跑起来第一个 Pytest 用例
- [ ] `pip install pytest`
- [ ] 新建 `test_posts.py`，写一个 `test_` 开头的函数，里面用 `assert`
- [ ] 命令行运行 `pytest`
- **产出**：终端出现 `1 passed`（第一个测试用例跑通）
- 提示：用例里可以直接写一个最简单的 `assert 1 == 1` 先验证环境，再换成真接口

### D2｜用 fixture 提供 client
- [ ] 用 `@pytest.fixture` 定义一个返回 `ApiClient()` 的 fixture
- [ ] 用例**通过参数名**拿到这个 fixture 并使用
- **产出**：一个用 fixture 拿 client 的接口用例
- 提示：fixture 函数名 = 用例里写的参数名，pytest 自动注入

### D3｜fixture 的前置/后置（setup/teardown）
- [ ] 把 fixture 改成 `yield` 写法：`yield client` 前做准备、后做清理
- [ ] 了解 `scope`（function / module / session）的区别
- **产出**：一个带 `yield` 的 fixture（打印"开始/结束"验证执行顺序）
- 提示：`yield` 前面是前置，后面是后置（类似手工测试的"测试完成后清理环境"）

### D4｜参数化，一个用例跑多组数据
- [ ] 用 `@pytest.mark.parametrize` 给一个用例喂多组参数
- [ ] 例如：同一个接口，传不同的 `userId`（1、2、3）各自断言
- **产出**：终端显示同一个用例跑了 3 遍（3 passed）
- 提示：参数化 = 数据驱动的雏形，这是接口自动化的核心武器

### D5｜常用命令行（筛选和调试）
- [ ] `pytest -v`（显示详细用例名）
- [ ] `pytest -k 关键词`（按名字筛选用例）
- [ ] `pytest -s`（显示 print 输出，调试用）
- [ ] `pytest test_posts.py::test_xxx`（只跑某个用例）
- **产出**：能熟练用命令挑用例跑
- 提示：以后用例多了，全靠这些命令定位

### D6｜conftest.py + 共享 fixture
- [ ] 新建 `conftest.py`，把 client fixture 挪进去
- [ ] 删掉 `test_posts.py` 里的 fixture，确认仍能跑通
- **产出**：fixture 放 conftest.py，多个测试文件都能用
- 提示：`conftest.py` 是 pytest 的"公共配置"，里面的 fixture 自动全局可用

### D7｜综合 + 复盘
- [ ] 把第 1 周的接口写成一套**完整测试**（放在 `test_posts.py`）：
  - 用例1：`GET /posts/1` 断言 `id == 1`
  - 用例2：`GET /posts?userId=1&_limit=5` 断言 `len == 5`
  - 用例3：**参数化**跑 `userId` = 1/2/3
  - 用例4：请求**不存在的地址**，断言优雅失败（拿不到数据 / 状态码非 200）
- [ ] 复盘：本周卡在哪、下周想加强什么
- **产出**：能 `pytest -v` 一键跑出整套结果 + 本周复盘
- 提示：这就是你简历上"接口自动化"的最小雏形
